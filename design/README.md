### pharpay-figma
**트리거:** flutter_pharpay 프로젝트에서 Figma URL 공유 또는 디자인 구현 요청 시

flutter_pharpay 프로젝트 전용 Figma → Flutter 위젯 변환기. 프로젝트 디자인 토큰(AppColor, AppTextStyles, AppRouter, SvgPicture)에 맞게 자동 변환.

- Figma 참조 코드를 프로젝트 컨벤션으로 adapt
- asset 존재 여부 확인
- 토큰 매핑 자동 처리
- 코드 제안만 출력 — 파일 직접 수정 안 함
